# 🔍 GitHub Profile Analyzer & Repository Explorer

A clean, responsive dashboard designed to fetch public GitHub user statistics, display interactive data charts for language distribution, and highlight top starred repositories.

![GitHub Profile Analyzer Screenshot](https://via.placeholder.com/800x400.png?text=GitHub+Profile+Analyzer+Preview)

## 🚀 Features

- **Profile Stats Overview:** View bio, avatar, public repos, followers, and following count.
- **Visual Analytics:** Interactive Doughnut chart powered by **Chart.js** displaying language breakdown.
- **Top Repositories:** Displays the top 6 repositories sorted by star count.
- **Dark Mode UI:** Designed with GitHub's modern dark theme palette.
- **Pure JavaScript:** Built using asynchronous REST API calls (`async/await`) without external framework dependencies.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Visualization:** [Chart.js](https://www.chartjs.org/)
- **API:** [GitHub REST API](https://docs.github.com/en/rest)
